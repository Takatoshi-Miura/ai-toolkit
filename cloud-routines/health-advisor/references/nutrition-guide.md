# 栄養バランスガイド

厚生労働省・農林水産省の「食事バランスガイド」を要約整理したもの。レポート作成時に参照する。

## 基本の考え方

1日の食事を「主食」「副菜」「主菜」「牛乳・乳製品」「果物」の5つの料理区分に分け、「つ(SV)」という単位で目安量を示す。上の区分（主食）ほどしっかり食べる必要がある。5区分のいずれかが欠けたり、1区分だけ極端に多いとバランスが崩れる。

## 5つの料理区分とSVの目安

| 区分 | 1つ(SV)の目安 | 一般的な成人（活動量ふつう）の1日目安 |
|------|--------------|--------------------------------|
| 主食 | ごはん小盛り1杯・食パン1枚 | 5〜7つ |
| 副菜 | 野菜料理1皿（小鉢） | 5〜6つ |
| 主菜 | 卵1個分・豆腐1/3丁分の料理 | 3〜5つ |
| 牛乳・乳製品 | 牛乳コップ半分・ヨーグルト1個 | 2つ |
| 果物 | みかん1個・りんご半分 | 2つ |

※ デスクワーク中心・活動量がふつう〜やや少なめの成人を想定した目安。運動量が多い人はさらに多くのエネルギーが必要になる。

## 推定エネルギー必要量（1日の摂取カロリーの目安）

「日本人の食事摂取基準（2025年版）」の30〜49歳男性の値。

| 身体活動レベル | kcal/日 |
|------|------|
| 低い（I） | 2,350 |
| ふつう（II） | 2,750 |
| 高い（III） | 3,150 |

- レポートでは、デスクワーク中心の生活を想定し「低い〜ふつう」の **2,350〜2,750kcal** を目安とする
- 参照体重（70kg）を前提とした値のため、体重がこれより軽い場合は実際の必要量はやや少なくなる
- アーティファクトの判定（`scripts/build_artifact.py`）では、目安下限から300kcal以内を「やや不足」、それ未満を「不足」とする（本スキル独自の区分）

## PFCバランスの一般的目安（成人）

- たんぱく質（P）: エネルギー比 13〜20%
- 脂質（F）: エネルギー比 20〜30%
- 炭水化物（C）: エネルギー比 50〜65%

`scripts/calc_nutrition.py` の `pfcRatio` はこの目安と比較して評価する。アーティファクトの判定（`scripts/build_artifact.py`）では、範囲外を「下限未満」（注意）と「上限超過」（要改善）に分けて表示する（本スキル独自の区分）。

## レポート作成時の使い方

1. 食事記録（「食事」シート）の各食品をこの区分（主食・副菜・主菜・牛乳/乳製品・果物）に分類する
2. 1週間の平均で、各区分が目安SVに対して不足/過剰かを評価する
3. `calc_nutrition.py` のPFC比率を上記の一般的目安と比較し、偏りがあれば指摘する
