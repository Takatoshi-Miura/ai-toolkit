# レポートの構成と文章ルール

週平均・目安・前週比はアーティファクトの「今週の4指標」「週次推移」に表示されるため、レポート本文では再掲しない。

## 構成

見出しはこの順・この名前で書く。

| 見出し | 内容 |
|------|------|
| `# 健康レポート（YYYY-MM-DD）` | 直下に対象期間と欠損・反映ラグの注記を1〜2文（反映ラグは「仕様通り」と書き、異常扱いしない） |
| `## 日別の記録` | 日付を行にした統合表1つ（日付・朝食・カロリー・P比率・F比率・歩数・睡眠）。平均行は付けない |
| `## 食事` | 目安との比較結果を箇条書き2〜3件。料理区分は表にせず、不足している区分を1件にまとめる |
| `## 運動` | 箇条書き1〜2件 |
| `## 睡眠` | 箇条書き1〜2件 |
| `## 健康診断` | 最新PDFの受診日を1行。前回から判定が変わった項目とC以下の項目だけの表（項目・今回・前回・判定）。新しいPDFがなければ「前回から変更なし」の1行 |
| `## 気になる兆候` | Phase 2.5の仮説3〜5件を「**仮説（〜の可能性）**: 根拠の数値1文」で。末尾に「いずれも数値データからの推測です」を1回だけ書く |
| `## 改善アドバイス` | 表（アドバイス｜理由）。最大6件 |
| 末尾 | `---` の後に免責1行と、目安値の出典1行 |

## 文章ルール

- 1項目1文、長くても2文。前置き・言い換え・まとめの文は書かない
- 同じ事実を複数のセクションで繰り返さない。数値は日別の記録表にあるものを必要な分だけ引用する
- 週平均の表・前週との比較表・データ取得状況の表は作らない
- LifeGraphの時間データ（仕事・パートナー等）は独立したセクションにせず、仮説の根拠としてのみ使う
- 医療的な断定はせず、健康診断の所見には「評価は医療機関にご相談ください」を1回だけ添える
