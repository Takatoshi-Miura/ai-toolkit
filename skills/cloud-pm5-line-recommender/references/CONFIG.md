# 設定

## 宛先・調査条件

以下は環境変数から読み込む（このファイルには機密・個人情報を記載しない）：

- `LINE_GROUP_ID`: 送信先の LINE グループ ID
- `HONEYMOON_CONDITIONS`: 調査条件（JSON文字列。エリア・旅行時期・泊数・予算・出発地・避けたいもの・同行者等のキーを持つ）

## 除外条件

- references/history.md に含まれる行き先はすべて選ばない
- 1回の実行につき候補を1件提案する

## メッセージフォーマット

以下のテンプレートに沿って本文を組み立てる。

```
🚩おでかけ候補🚩

■{旅行先名}({都道府県名})
{URL}

■交通手段・アクセス
ホテルオークラ神戸から {アクセス方法・所要時間・概算交通費}

■2人合計予算目安
交通費: 合計 約{金額}円

💡ちいぽよのおすすめポイント💡
 {おすすめ理由を詳しく}
```

- 「交通手段・アクセス」は必ずホテルオークラ神戸を出発地として記載する（`HONEYMOON_CONDITIONS` の出発地は使わない）
- 「2人合計予算目安」はホテルオークラ神戸から候補地までの往復交通費のみを合計した金額とする（宿泊費は含めない）

## おすすめ理由記載時の注意点

- 以下のスタイルに従って記載すること
    - references/chipoyo.md
- 書き出しは「ねえねえ ちーちゃ！」から始めること
