# 設定

## 宛先・調査条件

以下は環境変数から読み込む（このファイルには機密・個人情報を記載しない）：

- `LINE_GROUP_ID`: 送信先の LINE グループ ID
- `GACHA_KEYWORDS`: 調査対象のキャラクター・作品名（カンマ区切り。例: `ドラゴンクエスト,マイメロディ,にっこりーの`）

## 調査対象

- `GACHA_KEYWORDS` のいずれかに関連するカプセルトイ（ガチャガチャ）の**新商品**
- 新商品とは、実行日から見て「直近1か月以内に発売された」または「これから発売予定（発表済み）」のものを指す
- 公式情報（バンダイ ガシャポン公式、タカラトミーアーツ、キタンクラブ、ケンエレファント等のメーカー公式サイト）を優先し、URL は商品個別ページを記載する

## 除外条件

- references/history.md のテーマ `gacha` の行に含まれる商品（商品名または URL が一致するもの）はすべて選ばない
- テーマ `honeymoon` の行は過去テーマの記録のため、除外判定には使わない
- 1回の実行につき商品を1件提案する

## メッセージフォーマット

以下のテンプレートに沿って本文を組み立てる。

```
💊ちいぽよガチャじょうほう！💊

■{商品名}
{URL}

■発売日
{YYYY年M月D日}

■値段
1回 {金額}円

💡ちいぽよのおすすめポイント💡
 {おすすめ理由を詳しく}
```

- 「発売日」は公式情報の発売日（店頭への導入開始日）を記載する。日付まで確定していない場合は `2026年12月下旬` や `2026年12月予定` のように公式の表記どおりに記載し、確認できない場合は `不明` と記載する
- 「値段」は1回あたりの税込価格を記載する。公式情報で確認できない場合は `不明` と記載する

## おすすめ理由記載時の注意点

- 以下のスタイルに従って記載すること
    - references/chipoyo.md
- 書き出しは「ねえねえ ちーちゃ！」から始めること
- ラインナップ（全何種か）など、ワクワクする情報を盛り込むこと（発売日は「■発売日」欄に記載済みのため、本文で繰り返さなくてよい）
