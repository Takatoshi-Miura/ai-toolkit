# 設定

## 宛先・調査条件

以下は環境変数から読み込む（このファイルには機密・個人情報を記載しない）：

- `LINE_GROUP_ID`: 送信先の LINE グループ ID
- `MYHOME_CONDITIONS`: 調査条件（JSON文字列。物件種別・購入期限・エリア・通勤条件・予算・築年数・間取り・駐車場・ペット可否・騒音や水害や虫の少なさ・コンビニ/スーパーの徒歩圏内等のキーを持つ）

## 除外条件

- references/history.md に含まれる物件はすべて選ばない
- 1回の実行につき候補を1件提示する

## メッセージフォーマット

以下のテンプレートに沿って本文を組み立てる。

```
🍄きのこハウス候補🍄

■{物件名}({市区町村名})
{掲載URL}

■最寄り駅・通勤経路
{最寄り駅} → 新宿駅まで約{所要時間}分（{利用路線}）

■物件概要
・価格: {価格}万円
・築年数: 築{年数}年（{築年}年築）
・間取り: {間取り}
・駐車場: {駐車場情報}

💡ちいぽよのおすすめポイント💡
 {おすすめ理由を詳しく}
```

## おすすめ理由記載時の注意点

- 以下のスタイルに従って記載すること
    - references/chipoyo.md
- 書き出しは「ねえねえ ちーちゃ！」から始めること
